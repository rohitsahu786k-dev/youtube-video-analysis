# Processing cost and throughput

Successful structured inference calls record provider-reported prompt, output and total token counts in SQLite usage records. The dashboard displays measured usage, not hardcoded dollar estimates. Google AI Studio is the billing source; file upload, video, thinking tokens, retries and answer generation may affect actual charges.

Use representative short videos first. Concurrency defaults to two videos; reduce VIDEO_PROCESS_CONCURRENCY for low quotas. Audio chunks limit context size, clipped visual scans cover the timeline, event frame windows preserve chart detail, and prior-entry evidence sent to subsequent extraction is bounded. Pure teaching events without visible execution do not need a trade-extraction call. Existing proposal fingerprints prevent duplicate compilation.

MAX_CANDIDATE_EVENTS_PER_VIDEO caps detailed analysis and reports partial coverage. Reducing resolution, frame frequency or event caps may reduce recall/readability; do not treat a cheaper run as equally complete. Automatic reload is disabled to avoid expensive accidental restarts. Restarted video jobs currently replay processing rather than checkpointing every completed inference call.
