# Implemented research workflow and remaining limits

Implemented: durable playlist discovery and membership; restart-safe local video queue; real Gemini/FFmpeg processing; chunked transcripts; silent visual event discovery; per-event chart capture; original-image extraction/validation; multiple trade entries and exit updates; source-linked knowledge; execution and teaching pattern separation; automatic draft rules; causal cost-aware OHLC backtesting; read-only OANDA data adapter; gated expiring paper setups beside TradingView; truthful empty/error states; Python CI and isolated regression tests.

Runtime intentionally withholds unsupported values and suggestions. Live-market verification requires OANDA credentials, a reviewed unchanged rule, matching directly fetched candle data and adequate positive independent holdout results. CSV research works without those credentials.

Remaining limits: arbitrary discretionary strategies are not automatically executable. Only prior-range sweep/rejection and range breakout engines are available, with fixed targets and time exits. Multi-timeframe IFVG/order-block/session logic, tick-level fills, variable historical spreads, public authentication, multi-host workers, calibrated probability forecasts, audited account reconciliation and guaranteed profitability are not implemented. One-frame-per-second discovery and AI evidence readings can miss or misinterpret events. Restarted jobs replay inference rather than resuming every stage checkpoint.
