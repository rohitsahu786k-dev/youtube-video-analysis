# AI Pipeline
Local transcript rules cheaply identify obvious moments. A configurable high-volume model can add semantic candidates. Only selected frames around candidate timestamps are sent for vision. A reasoning model extracts structured trades and validation is a separate skeptical stage. Final cross-video synthesis/RAG uses the final model. Prompts are centralized in `src/ai/prompts` and outputs are validated with Zod. AI confidence is a score, not a calibrated probability.
