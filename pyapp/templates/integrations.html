  2. OAuth consent screen (External, add yourself as a test user) → Credentials → OAuth client ID → Web application.
  3. Authorised redirect URI:
  4. Set GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET, restart, then click Connect.

TradingView

Workflow A — native testing: generate Pine Script from an approved version (Strategy Editor or a run's “Pine & TradingView” tab), test it in TradingView's Strategy Tester, export the list of trades and compare it here.

Workflow B — independent engine: the Backtesting Workspace runs the same rules on licensed data, fully automatically, and labels every result with its engine and assumptions.

There is no remote control of TradingView's Strategy Tester: it has no official API, and scraping or credential sharing is deliberately not implemented. TradingView chart view is display-only.
